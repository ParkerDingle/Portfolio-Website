Dink Engine

A pickleball game with a machine-learning model inside

Play it Code

A 3D doubles game for practicing shot selection. When the ball comes to you, time slows down and a shot-value model scores every option, grades your choice and drives the AI players.

  • Trained a LightGBM model on 213,300 shots from 30,000 simulated rallies. Validation splits keep whole rallies together, so the model is never tested on a rally it trained on.
  • Checked calibration instead of stopping at AUC (0.58, expected when one shot only nudges who wins a rally). Predicted and actual win rates stay within 0.04 in every bin.
  • Exported the model to ONNX for the browser and to Luau for a Roblox version, with tests that hold each export to the original.
  • Wrote the pipeline for real match video: YOLO and ByteTrack follow players and ball, and a homography maps pixels to court feet.
  • A GitHub Actions job retrains the model on demand and opens a pull request with the new metrics.
Python · LightGBM · scikit-learn · ONNX · YOLO · OpenCV · TypeScript · Three.js

The Fight Camp

Data pipeline and projection model for a fantasy UFC league

See the league Code

A fantasy UFC league I run with four friends. A scraper collects fight results, a scoring engine turns them into points, and a projection model ranked fighters for our draft.

  • Scrapers for UFCStats and Wikipedia feed a SQLite database that now holds 758 fighters, 55 events and 604 bouts.
  • Two scheduled GitHub Actions jobs run it: one scores a card the night it ends, the other re-checks past events for amended results. Both are idempotent.
  • Projected each fighter's season as expected fights × expected points per fight, shrunk toward the division average so one lucky knockout can't outrank a proven contender.
  • Caught early scrapes storing round-one stats instead of whole-fight totals, fixed the parser, and modelled those stats instead of trusting numbers I knew were wrong.
  • 139 automated tests, including one that pins the Python scoring engine to the app's JavaScript.
Python · SQLite · requests · GitHub Actions · JavaScript
